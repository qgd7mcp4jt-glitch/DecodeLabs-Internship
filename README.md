# DecodeLabs Data Analytics Internship - Portfolio

## 📌 Overview
This repository contains my projects completed during the DecodeLabs Data Analytics Internship. It showcases the progression from data visualization in Excel to database management and analytical querying using SQL and Python.

---

## 📊 Project 1 & 2: Sales Dashboard (Excel)
- **Objective:** Cleaned and analyzed raw e-commerce data using Excel.
- **Key Deliverables:** Created Pivot Tables and an interactive Sales Dashboard to track key performance indicators (KPIs) and average order values.
- **Files:** Look for the `.xlsx` file in the repository to view the full interactive dashboard.

---

## 🗄️ Project 3: SQL Data Analysis (Python & SQLite)
- **Objective:** Built a complete data pipeline to migrate the raw e-commerce data into a structured SQL database.
- **Key Business Metrics Extracted via SQL:**
  - **Total Number of Orders:** 1,200 orders
  - **Total Revenue Generated:** $1,264,761.96
  - **Average Order Value (AOV):** $1,053.97
- **Files:** - `create_db.py` (Database Migration Script)
  - `run_sql.py` (SQL Query Script)
  - `project3.db` (The SQLite Database)

---

## 🚀 How to Run Project 3
1. **Install Dependencies:** `pip install pandas openpyxl`
2. **Build Database:** `python create_db.py`
3. **Run Queries:** `python run_sql.py`
